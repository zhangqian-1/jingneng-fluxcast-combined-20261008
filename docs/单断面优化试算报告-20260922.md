# 单断面优化可行性与离线试算报告（2026-09-22）

## 结论

可以采用单断面优化：每15分钟接收新的实际断面，只优化一个待执行的15分钟时段，不联合求解未来8步。七个燃机场站和19个新能源场站仍需在同一个模型中共同满足总供电需求。

本次用已有文件完成96次单断面独立试算，96次均获得可行最优解（求解器容差内）。在统一输入、购电能力和约束的89组可比案例中，与8步模型的首步结果在数值精度内一致。这是当前离线情景的结论，不代表所有工况下两种方法等价。

## 本次数据来源与边界

| 项目 | 本次采用方式 |
|---|---|
| 七站功率 | data/电机系参数需求下七份原始CSV，2025-06-05，每个目标时段使用前15分钟历史功率作为初值 |
| 风光可用数据 | 当前已替换的19份farm JSON，2026-09-19的96点，按既有离线读取规则使用 |
| 总供电需求 | 延用原离线回归情景：七站目标时刻历史功率之和，仅是等效需求；不是已经接通的平台独立负荷预测 |
| 运行状态与历史 | 按历史功率大于1 MW估计运行状态，推导持续时间及当日启停次数；没有冒充现场正式状态信号 |
| 价格与排放 | 使用当前config/station_parameters.json及DispatchConfig，碳价62.36元/tCO₂；发电成本含燃料，不重复计天然气费用 |
| 时间 | 历史CSV无时区，本次按北京时间做离线情景解释；没有修改原始时间，来源方时区确认仍适用于正式对接 |

历史追溯读取前7日，遇到更早缺测仅采用其后连续完整段；本次各站目标日与临近初值完整，保留至少6小时15分钟的连续前史。功率负值按已有离线口径以零计。风光沿用现有缺陷修正规则并写工作日志。跨日期数据仅按时刻组合用于算法回归，不是同日现场实测验证。

96次试算每次都重新读取历史实际初值，没有将前一次优化结果当作已执行的现场反馈。因此不能把这些结果说成连续闭环执行的全天成绩，也不报告虚构的全天节省率。

## 单断面方法的适用范围

当前案例中，后续7步没有改变首步的最优出力；这支持先采用单断面方案。单断面只看本时段，不能提前为未来负荷突增、风光骤降或机组长启动过程安排出力；“本时段最优”也不等于“全天最优”。当前模型是场站聚合模型，未细化实际燃气轮机的启动过程。

即使每次只优化一个时段，也不能清空前一实际断面、状态持续时间和当日启停次数。某一时段启动机组后，后续断面必须继续继承最小运行时间，不能在下一次计算中重新从零计数。真实接口每次应以新的现场反馈为准，不直接认定上轮建议已经执行。

## 正式切换时需要改哪些内容

1. 输入改为一个目标时段的总负荷/供电计划和19站风光可用功率；不再强制提供8点。仍需七站当前实际功率、运行状态、持续时间及当日启停次数。风光实际出力可以保留作展示，但限发后的实际值不自动等于可用上限。
2. 求解时段数设为1，保留上述状态和爬坡约束；输出7站出力、19站接纳及主网购电，共27个功率值。
3. 原调度计划仍可选，改为同一目标时段；有有效原计划才计算节省及减碳。
4. 接口的时序、去重、超时、失败状态及工作日志继续保留；正式接口UTC规则不改变。
5. 页面保持原布局，改为所选断面的实测/优化展示。历史曲线逐次追加已形成的断面结果，累计指标按不重叠的有效计划时段累加并防重；不能再标作未来2小时8步计划，也不能把计划累计当成实测电量。
