# 界面变量直接返回（20261001-r7）

按照平台2026-10-01要求，表格中的求和、日累计、比例、出力调整、电量和万元换算由算法计算，平台只绑定变量、按时间排序和格式化显示。正式接口仍为 `POST /api/v1/fluxcast/compute`，请求仍只有 `point_table`、`frames`、`renewable_data`，事件仍为 `JNH.Fluxcast.Compute`。

原54个数值点、8个字符串点及每天一次的96点预测全部保留。以下数值直接加入同一个 `result_point`；文字直接加入同级 `extra_info`。每项仍只有 `varname`、`timestamp`、`value`。数值是有限float；文字是string。不使用 `result_points`，不增加嵌套对象或把曲线塞进value数组。接收方不能再假定固定点数，必须按varname取值；更不能将所有数值或所有MW字段相加。

每次首次返回冻结源时段集合及汇总快照，重复请求不重复累计，后来完成的其他时段不改变旧请求的累计快照。跨日重新累计，缺少时段不补0。未来请求会纳入当时已归档的时段。SQLite结果和快照随数据卷持久化；当前没有自动删除期限。平台历史保留天数需平台确定，本次不虚构保存年限。

## 场站与曲线

七站code为 `GARD,JFRD,JQRD,JXRD,JYRD,SZRD,WLRD`。

| 模板变量 | 数组 | 含义 |
|---|---|---|
| {code}_actualMW | result_point | 请求末帧原始功率测点合计；timestamp为实测t |
| {code}_adjustmentMW | result_point | 下一时段优化出力减当前实测；timestamp为计划t+15分钟 |
| {code}_dayMWh | result_point | 当日已计算计划电量累计 |
| {code}_stationName | extra_info | 场站名称 |
| {code}_actualStatus | extra_info | 实测有效或缺测原因 |
| {code}_planStatus | extra_info | 原有计划运行/停机状态 |
| {code}_powerCurveMW | result_point | 本日已完成各时段计划出力，按timestamp排序绘图 |

任一原始功率测点缺失或非法时，不返回该站actualMW和adjustmentMW；不能用优化输入修补值冒充实测。调整量不是同一时刻预测误差。场站名称依据src/station_labels.py，功率测点依据src/platform_config.py。

供需平衡曲线直接用 `thermalPowerCurveMW`、`renewablePowerCurveMW`、`gridBuyPowerCurveMW`、`dispatchDemandCurveMW`。每种变量含多个时间点，每个value仍为float；只含已完成时段。全天预测仍用 `totalPowerForecastDayAhead`，北京时间00:00—23:45每天一次，其他响应不附带；平台保留当天已收曲线，不与调度需求曲线混用。既有首次发布响应丢失且跨时段重试的补取限制仍存在，本次没有增加确认回执协议。

19站farmId为 `1,2,3,4,7,8,10,11,12,13,16,17,19,20,21,22,23,28,29`，不是1—29连续29站。每站返回：

- result_point：原 `farm_{id}_MW`、`farm_{id}_available_MW`；新增 `farm_{id}_capacityMW`、`farm_{id}_id`。
- extra_info：`farm_{id}_stationName`、`farm_{id}_displayOrder`。
- result_point的 `renewableFarmCount=19.0`；extra_info的 `renewableDisplayLabel="绿色消纳"`。

名称、容量依据config/renewable_capacities.json。显示顺序沿用原图前五站1、16、19、8、2，其余按farmId升序；序号为两位字符串。康保150.8 MW仅是当前配置，现场容量和上游超限口径未核实，以farm_1_capacityStatus说明。

## 条件返回与文字状态

原有有效参考计划比较才返回baselineCostYuan、costSavingYuan，并新增本时段万元点 `baselineWanYuan`、`costSavingWanYuan`。累计全部源时段均有有效同口径比较才返回 `baselineDayWanYuan`、`costSavingDayWanYuan`；累计基准大于0才返回 `costSavingDayPct`。可为负节省，不能冒充实测事后收益。当前在线实测事后匹配及同需求回算未接通；缺比较时省略数值，由comparisonDisplayStatus说明。

其余extra_info：`displaySchemaVersion="20261001-v1"`、`currentPeriodLabel`、`dailyPeriodLabel`、`actualTimeLabel`、`daySummaryStatus`、`powerShareStatus`、`renewableAcceptanceStatus`、`peakGridBuyStatus`。峰段购电的时间范围及最大/平均规则未约定，因此仅返回原因，不能用截图162 MW作默认值。等待、失败、过期仍两个数组均为空。

正常单时段、七站实测有效且需求和新能源分母非0时，数值153点、文字71点；每增加一个同日已完成时段，返回曲线多11点；当天附带预测再加96点。原计划比较、缺测和零分母会改变数量，以上仅为样例计数。真实容器联调及225项测试验证见交付记录。
