# 停机零负荷与负功率处理

现场反馈：SZRD_10DCS02FA133、SZRD_10DCS02FA134为0，JQRD_10CBA00FA108XQ93为-0.2 MW；JQRD_11MBL11CT010XQ01环境温度为17.76℃。这组数据不能作为缺测拒绝。

## r8规则

1. 明确传入的数值0是正常功率，允许部分机组、整站或七站全部为0；不沿用之前的正功率填补。
2. 对src/platform_config.py中明确列出的发电功率测点，有限负值按max(原值,0)处理。每个机组测点先归零，再汇总场站，不能先求和后归零。例如100和-0.2得到100 MW。
3. 同一规则用于单点预测、96点预测、优化实际断面/启停推断及界面actualMW与adjustmentMW。原始请求不被覆盖；日志记录原值、替换值、测点和时间。原预测模型文件和依赖不改动，由封装在调用前处理。
4. 只处理发电功率测点，温度17.76℃保持17.76；负温度也不归零。新能源预测、价格、优化输出及负预测目标的原有约束不受此规则影响。
5. 该站有负功率归零时，extra_info中原{code}_actualStatus返回“实测有效（负功率归零）”；actualMW为按此规则处理后的合计。displaySchemaVersion更新为20261006-v2。

原POST /api/v1/fluxcast/compute、三个请求字段、result_point及extra_info结构保持不变；不增加新接口。初始化代理使用同样的功率规则。

## 缺测与运行边界

null、缺字段、空字符串、布尔值、非有限数与明确的0不同；本次不把真正缺测自动当成已知停机。优化侧仍按既有缺测策略处理，缺少可用起始历史时明确报错，界面不将补值称为实测。两个原模型的功率缺测填零与天气因果前填策略保持原样。

本次修复的是负测量值导致拒绝或错误延续原正功率的问题。0值原来已被接受，新增专门的零负荷回归验证。正常的模型冷启动历史不足、天气历史缺测、15分钟时间轴不合法、求解不可行仍需分别处理，不能凭零负荷修复承诺所有现场错误消失。

升级保留原数据卷；已归档求解结果及预测缓存不批量删除或重算。新请求采用新规则，历史已完成方案仍保持原归档。仅依据汇总功率估计场站状态，未凭此新增几十台机组的独立启停优化模型。

## 验证

tests/test_shutdown_power.py覆盖全部功率为0/负数、运行转停机、逐测点归零后求和、原始请求不变、负温度不被归零、预测代理和截图四项值。scripts/check_shutdown_power_live.py在已预热的隔离单容器中运行真实模型及优化，禁止针对生产容器执行。
