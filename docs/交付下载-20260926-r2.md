## 下载与启动

受服务器单文件限制，完整离线ZIP按64MiB分卷。登录项目后将 assemble.ps1 下载到空目录，在Windows执行：

```powershell
powershell -NoProfile -File .\assemble.ps1 -Download
```

输入有项目访问权限的GitLab账号密码，脚本只用于本次登录，不保存密码。自动下载、逐卷校验、按编号合并并校验整包SHA-256。也可在软件包页面手动下载所有分卷及脚本，在同一目录执行 `powershell -NoProfile -File .\assemble.ps1`。

Linux下载全部分卷后：

```sh
cat forecast-dispatch-20260926-r2.zip.[0-9][0-9][0-9] > forecast-dispatch-20260926-r2.zip
sha256sum forecast-dispatch-20260926-r2.zip
```

整包大小、分卷数和校验值以manifest.json为准。解压后Windows运行start.ps1，Linux运行sh start.sh。需要已启动的Linux Docker Engine及Compose；本包架构为amd64，默认接口端口18768。
