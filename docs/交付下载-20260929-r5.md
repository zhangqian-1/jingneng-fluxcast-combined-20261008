# 20260929-r5：当天预测缺失自动补算

本版保持一个容器、一个公开端口及原POST /api/v1/fluxcast/compute请求契约，增加当天预测候选缺失时的自动补算。用预测日零点前的真实历史快照调用原全天模型，不改原模型、不写在线缓存、不使用当天实测补预测。

每天首次优化成功且完整自然日曲线可用时，同一result_point返回30个常规数值点和96个totalPowerForecastDayAhead；其他正常时段返回30点，extra_info保持8个字符串。相同发布请求重试重放相同批次。没有08:30限制，曲线覆盖北京时间00:00—23:45，末点代表到24:00。

仍需真实历史截至前日23:45至少672个连续15分钟点，以及原模型所需天气和状态上下文。历史不足时报告缺失，需补齐真实输入；不能无数据补算。新能源联调输入是明确测试情景，不能据此声称现场闭环完成。

平台须按日期保存当天曲线，后续未附带96点时保留已有曲线，跨日不得拿昨天的曲线冒充今天。仓库提供[保存示例及补算说明](当天曲线补算及平台缓存-20260929.md)，平台实际代码不在本仓库，本次未部署平台界面。
