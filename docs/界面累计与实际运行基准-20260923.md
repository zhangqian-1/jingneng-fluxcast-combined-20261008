# 累计展示与实际运行基准

## 展示口径

恢复原工程页面的布局和名称：七站联合优化、全天供需平衡、当前断面、七站调度出力、累计调度分析、新能源消纳。默认时间轴位于 23:45，累计范围为 00:00—24:00。拖动时间轴后，累计范围包含当前选中的完整 15 分钟时段。

顶部成本、碳排放、电量，分析文字、成本明细及新能源接纳率按该范围累计。比例由累计量重新相除，不累加各时段百分比。右侧功率构成、场站出力和新能源功率仍显示所选时刻的 MW；累计电量显示 MWh。只保留新能源面板独立放大，两个对比数值使用相同字号。

## 实际运行基准的建立

本页优化需求来自 2025-06-05 同期七站实测发电功率合计，因此以这七站提供的同一电量为比较边界：

- 实际运行基准：使用同一目标时刻的七站实测发电功率，按现有单位发电成本、碳排放系数、碳价及估计启停事件核算。
- 优化方案：使用已保存的相同供电需求下的优化结果，含燃机、风光替代及主网补充供电。
- 未将上一时刻实测功率冒充同期基准。求解初始状态仍取上一时刻，不改动已有优化方案。
- 原始 CSV 未修改。运行状态仍按实测功率大于 1 MW 估计；核算结果不是历史财务结算或现场碳排放实测。
- 比较边界为七站原本发出的电量，不是全网历史供能。未虚构历史风光或购电实测，更未把风光预测计为历史弃电罚金。
- 风光采用现有 2026-09-19 离线情景，结果属于替代情景分析，不是现场已实现收益。正式在线比较仍使用平台提供的同期原计划，现有联合 API 契约不变。

同一时段的基准电量与优化侧燃机、风光和购电合计电量必须一致，否则拒绝建立对比，不生成节省率。
