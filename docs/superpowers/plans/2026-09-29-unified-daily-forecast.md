# 每日自然日预测联合返回实施计划

目标：按用户最新要求取消 08:30 限制，在原 compute 请求中返回下一时段优化和每天一批的 96 点预测；一个容器只公开优化入口所在端口。

接口沿用 point_table/frames/renewable_data、result_point/extra_info/event_key。单点仍为 totalPowerForecast，全天使用已提议的 totalPowerForecastDayAhead，避免违反原约定中 (varname,timestamp) 唯一性。不以全天首点替换优化采用的单点值。

发布日期按末帧对应的北京时间日期。保存前日23:45输入对应的当天00:00—23:45整批预测；当天第一次优化成功且候选可用时发布。禁止拼接滚动批次或以实测替代预测。响应保留原UTC口径。缺少日界线候选时只返回优化并给诊断状态。详见 docs/统一请求与每日全天预测-20260929.md。

每天一批指唯一逻辑批次：同一发布请求重试重放同一结果，以便响应丢失后恢复；其他时段不带这 96 点，不输出 null 或零值占位。SQLite 持久保存发布日期、来源断面和完整预测，重启不重复生成批次。只有优化成功、全天 96 点完整有效且属于当天时才能写发布记录。

全天服务暂不可用、未就绪不能阻止正常优化返回；通过 X-Fluxcast-Day-Forecast 响应头和工作日志说明状态，保持原 JSON 顶层结构和 8 个字符串状态。每次有效请求及原初始化代理都向全天模型提供历史，初始化不能消耗发布机会。
