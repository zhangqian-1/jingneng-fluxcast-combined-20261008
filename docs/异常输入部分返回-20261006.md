# 异常输入部分返回（20261006-r9）

依据《测试报告-新能源预测数据联调-20260918.md》第五项“数据异常时的计算结果处理”，以及平台2026-10-06确认：仅省略无法计算的结果，正常返回独立可计算结果，并记录异常来源和受影响结果。r9同时包含r8的停机零负荷、负功率归零修复。

## 接口约定

沿用POST /api/v1/fluxcast/compute、point_table/frames/renewable_data、event_key=JNH.Fluxcast.Compute。有效96帧请求中，燃机值或新能源记录异常导致无法优化时，返回HTTP 200及部分结果；不以0或null占位。

- result_point仍为有限数值点，每项varname/timestamp/value；省略无法计算的点。
- extra_info仍为字符串点，同样三个字段。部分响应固定增加：
  - calculationStatus：`部分结果：未生成优化方案`。
  - calculationDetail：异常测点/farmId、异常时间及具体原因。
  - unavailableResults：受影响的结果范围。
- 部分响应不返回balanceStatus、七站planStatus，也不能让平台把上轮优化结果作为本轮成功方案。
- 完整成功仍沿用既有返回；新增三个说明字段只用于部分响应。

完整结构见[部分返回示例](../examples/platform-partial-result.json)：farmId=29缺失，其余独立数据继续返回。该文件是合成测试样例，不是现场测量或生产预测。

## 依赖关系

| 异常 | 仍可返回 | 不能返回 |
|---|---|---|
| 某farmId缺失、全空、目标日缺行或该场数据无有效替代 | 有效七站实测、其他场有效可用预测；功率历史有效且模型就绪时的单点预测，以及可独立发布的当天96点预测 | 异常场available；联合优化全部出力、成本、碳排、电量、占比、调整量和包含本轮的累计/优化曲线 |
| 某燃机功率测点无有效起始历史 | 其他有效站实测、有效新能源预测；该站末帧全部实测有效时仍可返回末帧合计 | 无法确定的该站实测；依赖不完整功率历史的预测；联合优化及派生指标 |
| 新能源批次混合或预测目标日缺失 | 有效燃机实测、独立有效负荷预测 | 无法确定有效批次/目标日的新能源预测及联合优化 |
| 部分返回时单点模型未就绪、失败或返回过期目标 | 有效燃机实测、有效新能源预测 | 无效单点预测及依赖它的调度结果 |

七站、19场新能源、购电属于同一个功率平衡优化问题，不能删掉一个缺失站或假设其为0后，把剩余站出力称为有效优化结果。`farm_*_available_MW`是可用预测，不能替代`farm_*_MW`接纳计划；部分响应中的totalPowerForecast是模型预测，本轮没有完成优化。

## 计算和日志

0是有效停机数据；有限负发电功率逐点归零，温度不变。既有有效前值填补与首点新能源容量限幅规则保留，并逐项记录原值、替代值、测点和时间。无法按既有规则确定值时，不再全量清空独立结果。

每场新能源独立解析原长表，沿用timeSeries=1、结束时刻减15分钟、目标日96点、容量及批次约束；不补零伪造缺场，不拿前一天数据替代目标日。返回时间沿用原请求样式：实测为t，预测/计划为t+15分钟。日志stage=platform_partial_results，记录input_issues、returned_results、unavailable_results及原错误原因；日志存储失败仍明确报错，不静默忽略。

部分响应不生成或冻结优化归档，输入补齐后可以在原有效时段内重试。已有正常归档时，不允许异常请求覆盖；过期/未来断面、错误时间轴、缺少必填顶层字段、非法JSON、point_table不符合原约定仍按原4xx错误处理，不以“部分结果”绕过契约校验。renewable_data可为[]，此时返回其他独立值并明确19场缺失；null仍不符合数组类型。

无异常数据时的模型冷启动202、求解器/存储等系统故障的原响应不在本次数据异常降级范围内。平台继续按日保存已收到的96点曲线，后续响应未附带不清空；原有跨时段丢包补取限制没有在此版本中改变。
