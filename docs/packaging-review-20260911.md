## 尚未闭环的事项

| 项目 | 当前实现或证据 | 未闭环原因/所需动作 |
|---|---|---|
| 返回变量唯一性 | 同一场站变量名出现96次，以时间戳区分 | 原文件要求varname唯一；须由平台确认是否认可组合键，不能擅改订阅变量名 |
| 新能源上游 | 已有HTTP获取、容量及时间轴校验，不回退历史文件 | 真实URL、字段和实际19站响应仍需双方联调 |
| 目标环境验收 | 本地双求解器运行成功；交付检查包含ARM wheel核查 | wheel检查不等于Kylin ARM实机、容器、许可证及分钟级性能验证 |
| 求解器交付口径 | 当前默认HiGHS，仍支持Gurobi | 原文件列Gurobi性能/ARM许可交付物；不能因HiGHS可用就把这些要求标成完成 |
| 发电成本口径 | 原表发电成本再加气价×热耗/低位热值 | 原表是否已含燃料尚不清楚，有重复计费风险；需参数提供方确认 |
| 场站上下限 | 当前站级Pmax使用历史非供暖在线99.5%分位与原表上限的较大值，再受装机容量限制 | 不是直接照抄原表上限；需确认该聚合口径是否可执行，不能仅凭图中未越线判断物理正确 |
| 基准与减碳 | 等效负荷与基准燃机同源；碳约束只要求不超过基准 | 情景成本降低不能直接视为真实运营收益；要净减碳需另行明确业务目标，不在本轮擅改 |
| 开停与电网 | 有日初状态、日内启停限制；购电能力按负荷峰值20%设置 | 缺跨日连续开停时长、现场初始状态和真实联络线容量 |
| 购售电能力 | 当前工作区已采用import_only，售电固定0 | 保留售电价格字段不等于已启用售电；若平台预期买卖双向，需确认当前业务范围 |
| 更新同一天预测 | 求解/完成后的不同输入返回409 | 没有面向平台的同日新版本重算入口；不能将已完成批次悄悄覆盖 |
