# 20260929-r4：单容器、单端口、统一请求

历史版本：新部署请使用[20260929-r5](交付下载-20260929-r5.md)，新增当天预测缺失自动补算及平台曲线保存示例。本页记录r4当时的行为。

本版将单点预测、全天预测和优化合为一个交付镜像、一个运行容器，算法之间在容器内部调用，只公开默认18768端口。平台仍调用 `POST /api/v1/fluxcast/compute`；三个输入字段及数值/字符串数组结构不变。

- 通常返回30个优化相关数值点及8个extra_info字符串点。
- 当天第一次优化成功且自然日曲线可用时，同一result_point再附带96个totalPowerForecastDayAhead，共126点。
- 全天曲线覆盖北京时间当天00:00—23:45，末点代表到24:00。没有08:30限制，每天一个逻辑批次；同一发布请求重试重放相同结果。
- 必须连续提供历史并覆盖前一日23:45输入。缺少当天候选时不拼接滚动预测；优化仍正常返回，诊断状态见响应头及日志。
- 价格GET/PUT仍为七站14项，不含天然气价；平台须保存当天预测，其他时段不附带96点时不能清空曲线。

详细时间口径、初始化和异常说明见[统一请求契约](统一请求与每日全天预测-20260929.md)。平台自身的实时界面和生产部署仍需现场联调，仓库附带dashboard为历史情景展示。
