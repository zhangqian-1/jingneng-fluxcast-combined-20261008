## 下载与启动

受服务器单文件大小限制，完整离线ZIP按64MiB分卷。登录项目后，把assemble.ps1下载到空目录并运行：

```powershell
powershell -NoProfile -File .\assemble.ps1 -Download
```

使用有项目权限的GitLab账号登录，脚本不保存密码。自动下载、逐卷校验、合并并校验整包SHA-256。也可手动下载全部分卷与脚本，在同一目录执行 `powershell -NoProfile -File .\assemble.ps1`。

Linux下载全部分卷后：

```sh
cat forecast-dispatch-20260926-r3.zip.[0-9][0-9][0-9] > forecast-dispatch-20260926-r3.zip
sha256sum forecast-dispatch-20260926-r3.zip
```

整包校验值以manifest.json为准。解压后Windows运行start.ps1，Linux运行sh start.sh。需要已运行的Linux Docker Engine及Compose；本包架构为amd64。启动脚本加载三套镜像并等待三个服务健康，无需主机安装Python或unzip。

| 入口 | 默认端口 | 作用 |
|---|---|---|
| /api/v1/fluxcast/compute | 18768 | 原三字段平台请求，单点预测→下一时段优化 |
| /api/v1/fluxcast/forecast/compute | 18768 | 单点预测补历史/计算，两字段原预测请求 |
| /api/v1/fluxcast/compute | 18780 | 独立原版24小时预测，两字段原预测请求 |

18780是可配置的独立服务端口，不是MD新增字段。优化仍只依赖内部forecast单点服务。原作者两套预测的请求、模型、镜像及ZIP均保持原样。直接调用原预测时使用原35个测点编码，具体示例见包内examples与原预测文档。

## 初始化与验收范围

单点模型至少需要288点连续历史，长模型至少需要672点；每批仍96帧，分别按时间顺序补传，天气缺测可能需要更多真实历史。两套缓存各自独立。健康检查通过只代表服务可用，历史不足仍返回等待原因。旧8步或96步优化不恢复。

交付包含两份原始预测ZIP、优化镜像、源码、接口依据、样例、独立HTML和联调记录。Windows与Linux各118项测试通过；真实历史分别验证1点和96点预测，优化HTTP输出29个浮点结果。新能源是明确标注的零出力测试情景，不代表生产收益。

独立长预测停机时单时段优化、重建容器后的缓存保留，以及离线启动结果见联调记录和[启动验证记录](http://117.78.35.35/api/v4/projects/56/packages/generic/forecast-dispatch/20260926-r3/offline-start.json)。上传不等于生产部署。麒麟ARM实机、真实遥信/购电参数、康保容量差异及现场平台闭环仍需现场验收；Windows启动脚本完成语法校验，本机未验证完整Windows Docker启动。
