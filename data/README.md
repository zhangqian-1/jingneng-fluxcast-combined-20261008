# 随项目交付的离线回归数据

**2026-09-22滚动接入说明：**现有燃机、风光材料作为实际数据素材保留。滚动服务必需实际运行状态、风光可用预测、总负荷预测/供电计划；原调度计划可选，仅作效果对比。实际功率不等于未来原调度计划，不将本目录文件自动充作预测或原计划。原始JSON的predictedTime/predictedPower字段及文件来源不改写；历史回归程序仍按原协议读取，以下日期说明只针对历史材料。七站CSV无时区标识，真实导出时区仍需来源方确认后才能转换上报。

本目录包含7份燃机场站CSV、19份新能源JSON和2份Excel参数表。19份新能源JSON已全部替换为用户提供的 `renewable_20260918.tar.gz` 中的原始文件，字节内容保持一致；七站历史CSV及参数表保留。共28份输入、66,046,581字节，`manifest.json` 记录大小、SHA-256和预测来源。运行 `uv run python scripts/check_delivery.py` 可校验交付完整性。

新能源批次为 `202609180800`，覆盖2026-09-19至2026-09-28，每场960点，间隔15分钟，功率单位MW。`predictedTime` 是北京时间的时段结束时间，读取时减15分钟后按目标日期选择96点。默认离线新能源日期为2026-09-19，可通过 `RENEWABLE_FORECAST_DAY` 指定，不会自动切换日期或回用旧样本。默认负荷情景仍为2025-06-05历史数据，结果中分别记录负荷日期和新能源日期。

默认 `INPUT_PATH=./data`，仅离线功能读取本目录。原96点计算接口必须由请求提交renewable_data，无文件/HTTP自动兜底；新增滚动接口也没有预测兜底。旧测试预测备份仅在本地output/backups，不参与滚动计算或交付。
